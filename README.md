# مبدل متن فارسی به PDF + هوش مصنوعی (Persian Text-to-PDF Converter + AI)

ابزاری کامل، تحت وب و همه‌کاره است که متن فارسی را به فایل‌های **PDF**، **PNG** و **Word** تبدیل می‌کند. این ابزار به‌طور ویژه برای خروجی مدل‌های زبانی طراحی شده است. همچنین این برنامه به **ده‌ها پروایدر هوش مصنوعی** متصل می‌شود و متن را به‌صورت درون‌خطی ویرایش، بازنویسی و پردازش می‌کند. تمام پردازش‌ها در سمت کاربر (Client-Side) انجام می‌شوند و نیازی به سرور مرکزی وجود ندارد.

**آپدیت بزرگ جدید:**

*   **اتصال به هوش مصنوعی:** این نسخه از ۱۰ پروایدر مختلف پشتیبانی می‌کند؛ از جمله Ollama لوکال، LM Studio، OpenAI، Anthropic، Gemini، Groq، DeepSeek، OpenRouter، Qwen و هر سرویس سازگار با OpenAI.
*   **پردازش درون‌خطی با تگ `@ai`:** در هر جای متن، دستور خود را برای هوش مصنوعی می‌نویسید و نتیجه را مستقیماً در متن اعمال می‌کنید.
*   **تشخیص و نمایش فرمول‌های ریاضی:** این قابلیت با پشتیبانی از MathJax و حالت خودکار فیزیک کار می‌کند (`V_gs` به `$V_{gs}$` تبدیل می‌شود).
*   **هایلایت کد در ۱۳ زبان:** Python، C++، JavaScript، TypeScript، Java، C#، PHP، HTML، CSS، SQL، Bash، Go و Rust.
*   **پشتیبانی از جداول مارک‌داون.**
*   **شکست صفحه‌ی هوشمند و قابل جابجایی** (Drag & Drop) برای مدیریت PDF چندصفحه‌ای.
*   **آپلود فونت سفارشی TTF** (برای تیتر و متن).
*   **تم تاریک و روشن** با ذخیره‌سازی خودکار.
*   **خروجی Word** از طریق سرور Python محلی (اختیاری).
*   **دریافت خودکار لیست مدل‌ها** از پروایدر (Ollama، Gemini، OpenAI و دیگران).

## 🎯 چرا این ابزار ساخته شد؟

بسیاری از مدل‌های زبانی هنگام تولید متن، از کاراکترهای نشانه‌گذاری مانند `#` برای تیتر، `*` برای تأکید، و بلاک‌های کد مارک‌داون استفاده می‌کنند. علاوه بر این، چند مشکل دیگر نیز وجود دارد:

1.  **مشکل فرمت:** خروجی مدل‌های زبانی معمولاً متن خام است، نه یک سند تمیز با فونت درست و صفحه‌بندی مناسب.
2.  **مشکل فونت فارسی:** اکثر ابزارهای PDF خارجی از فونت فارسی و RTL به‌درستی پشتیبانی نمی‌کنند.
3.  **مشکل تکرار:** برای ویرایش هر بخش از متن با هوش مصنوعی، کاربر باید بین ابزارهای مختلف جابجا شود.
4.  **مشکل فرمول و کد:** فرمول‌های ریاضی و بلاک‌های کد در تبدیل به PDF خراب می‌شوند.

این ابزار همه‌ی این مشکلات را در **یک صفحه‌ی وب واحد** حل می‌کند.

## 🖥 راه‌اندازی خروجی Word (اختیاری)

خروجی Word به یک سرور کوچک Python نیاز دارد که از `python-docx` استفاده می‌کند.

### نصب
```bash
pip install python-docx flask flask-cors
```

### فایل `serve_word.py`
یک سرور کوچک Flask می‌سازید که روی `127.0.0.1:8765` گوش می‌دهد و endpoint `/generate` را پیاده‌سازی می‌کند تا متن را به `.docx` تبدیل کند.

### اجرا
```bash
python serve_word.py
```

یا یک فایل `start.bat` می‌سازید که خودش سرور را بالا می‌آورد.

> **توجه:** اگر سرور بالا نباشد، دکمه‌ی Word یک پیام خطای راهنما نشان می‌دهد و بقیه‌ی قابلیت‌ها بدون مشکل کار می‌کنند.

## 🖥 راه‌اندازی Ollama (برای هوش مصنوعی لوکال)

از [ollama.com](https://ollama.com) دانلود می‌کنید و نصب می‌کنید.

### اجرای مدل
```bash

```

### اجرا با CORS باز (مهم!)
```bash
OLLAMA_ORIGINS=* ollama serve
```

> ⚠️ اگر این متغیر ست نشود، مرورگر نمی‌تواند به Ollama وصل شود و خطای CORS دریافت می‌کنید.

### در اپلیکیشن
*   پروایدر: **🖥 Ollama (لوکال)** را انتخاب می‌کنید.
*   Base URL: `http://localhost:11434` را وارد می‌کنید.
*   روی **📥 دریافت لیست** می‌زنید و مدل را انتخاب می‌کنید.
